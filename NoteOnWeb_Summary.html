Product Summary & Competitive Guide

🔒 Note on Web (SecureNote)

เว็บแอปพลิเคชันจดบันทึกและบริหารจัดการผังความคิด ที่รวมความปลอดภัยระดับ Zero-Knowledge Vault, บอร์ดโพสต์อิทอิสระ, และขุมพลัง AI ไว้อย่างสมบูรณ์แบบ

✨ ฟังก์ชันการทำงานหลัก (All Core Features)
📝 Smart Note & Editor
  • WYSIWYG TipTap Editor: จัดรูปแบบครบ ตัวหนา/เอียง, สีข้อความ, ตาราง, โค้ดบล็อก, เช็คลิสต์
  • Autosave & History: เซฟอัตโนมัติ พร้อมดูประวัติการแก้ไขย้อนหลัง (Version History) และกู้คืนได้
  • Export ทันที: บันทึกออกเป็น Markdown (.md) หรือพิมพ์เป็นไฟล์ PDF
  • การจัดระเบียบ: สมุดบันทึก (Notebooks), ป้ายกำกับ (Tags), ปักหมุด (Pin), ถังขยะและกู้คืน (Trash)
📌 Sticky Board & Mindmap
  • Freeform Canvas: แปะโน้ตลงกระดานใหญ่ ลากย้าย หมุนองศา และปรับขนาดได้อย่างอิสระ
  • เส้นเชื่อมโยง Mindmap: ลากเส้นเชื่อมโยงความสัมพันธ์ระหว่างโน้ตเพื่อวางแผนงาน
  • สติกเกอร์ตกแต่ง: แปะเทปกาว หมุดปัก แสตมป์เร่งด่วน สร้างบรรยากาศเสมือนบอร์ดจริง
  • Kanban Mode: สลับมุมมองเป็นตาราง To Do, In Progress, Done ได้ในคลิกเดียว
🎙️ AI, เสียง & สแกนภาพ (OCR)
  • Speech-to-Text: พิมพ์ด้วยเสียงพูดอัตโนมัติ รองรับภาษาไทยและอังกฤษได้อย่างแม่นยำ
  • Voice Recorder: อัดเสียงพูด/การประชุมแนบไว้ในโน้ต พร้อมเครื่องเล่นเสียง
  • Image OCR: สแกนและถอดข้อความจากภาพถ่ายเอกสารลงในโน้ตทันที
  • AI Assistant: ช่วยสรุปเนื้อหา, ช่วยคิดไอเดีย, ขัดเกลาข้อความ และแนะนำแท็ก
🔐 Zero-Knowledge Vault
  • AES-256 Encryption: เข้ารหัสโน้ตลับบนเครื่องผู้ใช้ก่อนส่งขึ้นคลาวด์ แอดมินเซิร์ฟเวอร์ก็แอบอ่านไม่ได้
  • Master Password: กุญแจเฉพาะตัวผู้ใช้ ไม่มีการเก็บรหัสลับไว้ที่ฐานข้อมูล
  • Passkeys / WebAuthn: ล็อกอินสะดวกรวดเร็วด้วย Face ID, Touch ID, Windows Hello
  • Real-time Collaboration: แชร์ลิงก์โน้ต (อ่านอย่างเดียว หรือช่วยกันพิมพ์สดพร้อมกัน)

💎 5 จุดเด่นที่ทำให้ Note on Web แตกต่างและน่าใช้งาน
1. ความเป็นส่วนตัวระดับสูงสุด (Real Privacy)
ผู้ใช้มั่นใจได้ 100% ว่าข้อมูลรหัสผ่าน เอกสารลับ หรือบันทึกส่วนตัวจะไม่รั่วไหล เพราะถูกเข้ารหัสบนอุปกรณ์ด้วย AES-256 Vault ก่อนจัดเก็บ
2. รวมแอปจดโน้ตและแอปวางแผนไว้ที่เดียว (All-in-One Space)
ไม่ต้องสลับแอปไปมาระหว่างแอปจดบันทึกและกระดานไวท์บอร์ด เพราะมีทั้งโหมด Document ปกติ, กระดาน Canvas โพสต์อิทลากวาง และตาราง Kanban ในระบบเดียว
3. บันทึกได้สะดวกรวดเร็ว ไม่ต้องพิมพ์ (Voice & OCR)
รองรับการพูดเป็นข้อความภาษาไทย/อังกฤษ อัดเสียงบันทึกการประชุม และสแกนข้อความจากภาพถ่ายได้ทันที เพิ่มความคล่องตัวในการทำงาน
4. ความลื่นไหลและดีไซน์ระดับพรีเมียม (Modern Aesthetics)
ดีไซน์ Dark Mode และ Glassmorphism ที่สบายตา สวยงาม ตอบสนองไว ไม่มีอาการหน่วงเหมือนโปรแกรมขนาดใหญ่
5. เข้าถึงได้ทุกที่ ไม่มีข้อจำกัดเรื่องอุปกรณ์ (Web & PWA)
เปิดใช้งานผ่านเบราว์เซอร์ได้ทันทีบน Windows, Mac, iPad, iPhone และ Android ซิงก์ข้อมูลตรงกันแบบ Real-time
